# 화면 영역 캡쳐 도구 (Tkinter + MSS)

마우스로 드래그하여 **캡쳐 영역을 지정**하고, 지정한 영역을 버튼 클릭 또는 단축키로 반복 캡쳐하여 선택한 폴더의 `screen-region-capture` 서브 폴더에 날짜와 시간 기반의 파일명으로 자동 저장하는 GUI 도구입니다.  
멀티 모니터 환경(노트북 + 외부 모니터 등)에서 **전체 가상 화면(monitors[0])** 기준으로 오버레이를 띄우고, 선택 영역의 좌표를 오프셋 보정하여 캡쳐합니다.

## 주요 기능

- **저장 폴더 선택**: 프로그램 시작 시 결과물을 저장할 상위 폴더를 직접 선택 가능
- **마우스 드래그로 영역 지정**: 오버레이에서 자유롭게 캡쳐 영역 선택 (박스 표시)
- **단축키 지원**: 숫자 `1` 키를 눌러 즉시 캡쳐 가능
- **고속 캡쳐 지원**: 파일명에 마이크로초를 포함하여 연속 캡쳐 시에도 이름 충돌 방지
- **멀티 모니터 지원**: 모든 모니터를 포함하는 가상 화면 영역 지정 지원
- **DPI 대응**: Windows High DPI 설정을 적용하여 좌표 어긋남 최소화

## 요구사항

- Windows 10/11 권장
- Python 3.9+ 권장
- 패키지: `mss`, `Pillow`, `pyinstaller` (빌드 시)

## 설치

```bash
python -m venv venv
# Windows
venv\Scripts\activate
pip install -r requirements.txt
```

## 실행 및 빌드

### 스크립트 실행
```bash
python screen_region_capture.py
```

### 실행 파일(.exe) 빌드
```bash
pyinstaller screen_region_capture.spec
```
빌드 후 `dist/ScreenRegionCapture.exe` 파일이 생성됩니다.

## 사용 방법

1. 프로그램 실행 시 **저장 경로**를 선택합니다. (선택한 폴더 내에 `screen-region-capture` 폴더가 자동 생성됨)
2. **[영역 지정]** 버튼 클릭
3. 전체 화면에 뜨는 반투명 오버레이에서 **마우스로 드래그**하여 영역 선택  
   - `ESC`를 누르면 취소
4. **[캡쳐]** 버튼 클릭 또는 **숫자 `1` 키** 입력 → 이미지 저장
5. 화면을 다른 장면으로 바꾼 뒤에도 다시 버튼이나 단축키를 누르면 동일 영역을 계속 저장

## 출력 폴더 / 파일명 규칙

- **출력 폴더**: `[사용자 선택 폴더]/screen-region-capture/`
- **파일명**: `YYYYMMDD_HHMMSS_ffffff.png` (년월일_시분초_마이크로초)

## 참고 사항

- Windows의 디스플레이 배율이 모니터마다 크게 다를 경우 좌표 오차가 발생할 수 있습니다. 가급적 동일한 배율 설정을 권장합니다.
