# PRD – Screen Region Capture Tool

## 1. 목적 (Purpose)
멀티 모니터 환경에서 사용자가 한 번 지정한 화면 영역을 유지한 채,
버튼 또는 단축키로 반복 캡쳐하여 자동 저장할 수 있는 Windows 전용 데스크톱 유틸리티를 제공한다.

## 2. 대상 사용자
- Windows 환경에서 반복적인 화면 캡쳐가 필요한 사용자
- QA, 문서 작성, 교육 자료 제작, 개발 기록용 스크린샷 사용자
- 멀티 모니터 환경(노트북 + 외부 모니터)을 사용하는 사용자

## 3. 핵심 요구사항 (Functional Requirements)
1. 프로그램 시작 시 결과 저장 폴더 선택
2. 전체 가상 화면 기준 오버레이 제공
3. 마우스 드래그로 캡쳐 영역 지정 (박스 표시)
4. 지정한 영역을 프로그램 실행 동안 유지
5. 버튼 클릭 또는 숫자 `1` 키로 캡쳐 수행
6. 캡쳐 결과를 PNG 파일로 저장
7. 파일명은 날짜/시간/마이크로초 기반으로 자동 생성하여 중복 방지

## 4. 비기능 요구사항 (Non-Functional Requirements)
- Windows 10/11 지원
- 멀티 모니터 환경에서 좌표 정확성 보장
- High DPI 환경에서 좌표 오차 최소화
- 외부 서버 통신 없이 로컬 단독 실행

## 5. 제약사항
- macOS / Linux 미지원
- 프로그램 종료 시 영역 정보는 유지하지 않음 (메모리 기반)

## 6. 성공 기준
- 사용자가 영역을 1회 지정 후 연속 캡쳐 가능
- 다른 화면 전환 후에도 동일 영역 캡쳐 가능
- 파일명 충돌 없이 연속 저장 가능
