# 화면 영역 캡쳐 도구 (Tkinter + MSS)

마우스로 드래그하여 **캡쳐 영역을 지정**하고, 지정한 영역을 버튼 클릭으로 반복 캡쳐하여 `result` 폴더에 `IMG_001.png`, `IMG_002.png` 형태로 자동 저장하는 간단한 GUI 도구입니다.  
멀티 모니터 환경(노트북 + 외부 모니터 등)에서 **전체 가상 화면(monitors[0])** 기준으로 오버레이를 띄우고, 선택 영역의 좌표를 오프셋 보정하여 캡쳐합니다.

## 주요 기능

- 마우스 드래그로 캡쳐 영역 지정 (박스 표시)
- 프로그램 실행 동안 영역 유지(메모리)
- `캡쳐` 버튼 클릭 시 지정 영역을 PNG로 저장
- 파일명 자동 증가: `IMG_001.png`, `IMG_002.png`, ...
- 멀티 모니터(가상 화면) 영역 지정 지원
- 모든 GUI 문구 한글

## 요구사항

- Windows 10/11 권장
- Python 3.9+ 권장
- 패키지: `mss`, `Pillow`

## 설치

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
pip install -r requirements.txt
```

## 실행

```bash
python screen_region_capture.py
```

## 사용 방법

1. 프로그램 실행
2. **[영역 지정]** 버튼 클릭
3. 전체 화면에 뜨는 반투명 오버레이에서 **마우스로 드래그**하여 영역 선택  
   - `ESC`를 누르면 취소
4. **[캡쳐]** 버튼 클릭 → `result/IMG_###.png` 저장
5. 화면을 다른 장면으로 바꾼 뒤에도 **[캡쳐]** 버튼을 누르면 동일 영역을 계속 저장

## 출력 폴더 / 파일명 규칙

- 출력 폴더: `./result`
- 파일명: `IMG_001.png`, `IMG_002.png`, ...

## 멀티 모니터 / DPI 관련 참고

- 이 프로그램은 `mss.monitors[0]`(가상 화면)을 기준으로 오버레이를 만들고,
  오버레이 좌표에 `left/top` 오프셋을 더해 실제 화면 좌표로 변환합니다.
- Windows에서 디스플레이 배율(125%, 150%)이 모니터마다 다르면
  Tkinter 좌표와 실제 픽셀 좌표가 어긋날 수 있습니다.
  - 현재 코드에는 `SetProcessDpiAwareness(1)`을 적용했습니다.
  - 여전히 어긋남이 있으면, 모니터별 배율을 동일하게 맞추거나 DPI 보정 로직이 추가로 필요할 수 있습니다.
